# **Инструкция для бота (Промпт-ТЗ): Стандартизация названий и стилей треков**

**Назначение:** Приведение полей name и style в массиве JSON-треков к единому строгому формату.

### **Важное примечание по данным**

> **Все необходимые данные уже содержатся во входных файлах JSON и списке треков.**

> Скрипты с треками для переименования хранятся в этой папке D:\GitHub\LoopGenerator\data\loops

> Бот должен извлекать подвиды, заголовки и лады непосредственно из имеющихся названий (name), меток стилей (style), либо анализировать структуру нот (notes), если лад/тональность не указаны явно. Дополнительных внешних запросов не требуется.

### **Правила форматирования**

#### **1\. Поле "name" (Название трека)**

* **Структурный шаблон:** Renaissance \[Подвид\] \- \[Название / Описание\]  
* **Правила:**  
  1. Всегда начинается с ключевого слова Renaissance.  
  2. **\[Подвид\]** — жанр или музыкальная форма Renaissance (например: *Tourdion, Pavane, Folia, Passamezzo, Passamezzo Antico, Ricercar, Canzona, Lamento, Madrigal, Tiento, Romanesca, Sacred Chorale* и т.д.).  
  3. **\[Название / Описание\]** — исходная вариация или подзаголовок трека (например: *Point of Imitation, Hypnotic Bass, Dark Polyphony, Consonant Arch*).

#### **2\. Поле "style" (Стиль)**

* **Структурный шаблон:** Renaissance \[Подвид\] \[Лад/Тональность\]  
* **Правила:**  
  1. Состоит ровно из 3 элементом: Renaissance \+ \[Подвид\] \+ \[Лад/Тональность\].  
  2. **\[Подвид\]** должен полностью совпадать с подвидом из поля name.  
  3. **\[Лад/Тональность\]** — музыкальный лад или тональность (*Dorian, Phrygian, Aeolian, Lydian, Mixolydian, Major, Minor* и т.д.).  
  4. Если лад указан в названии/тегах — использовать его. Если не указан — определить по нотной гамме в массиве notes или подставить соответствующий гармонический лад по умолчанию (например, *Aeolian* для минорных тем, *Dorian* для Паван/Фолий).

### **Примеры преобразования (Before / After)**

#### **Пример 1 (Лад и подвид есть в названии):**

* **Было:**  
  {  
    "name": "Passamezzo Antico \- Hypnotic Bass",  
    "style": "Passamezzo Antico Transposed Dorian"  
  }
